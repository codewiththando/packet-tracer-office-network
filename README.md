# packet-tracer-office-network
Office network design and simulation using Cisco Packet Tracer for a 100m × 50m company building. The network includes routers, switches, VLANs, and wireless access points to support reliable communication and internet connectivity for office devices.
The network uses a hybrid topology combining hierarchical design principles. Different office switches connect to a central switch and router located in the machine/server room.

## Devices Used
- Router
- Layer 2 Switches
- Wireless Access Points
- Desktop PCs
- Laptops
- Printers
- Servers

## Features
- Wired connections for office computers
- Wireless access points for mobile devices
- Internet connectivity through ISP router
- Organized network structure for easy expansion

## Tools Used
- Cisco Packet Tracer
